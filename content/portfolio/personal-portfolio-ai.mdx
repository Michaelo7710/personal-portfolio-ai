# Personal Portfolio & Multimodal ATS-CV Engine: Rekayasa Web AI-Augmented

Platform portofolio personal rekayasa perangkat lunak modern yang mengintegrasikan kapabilitas Large Language Model multimodal untuk menjembatani kualifikasi lowongan kerja dengan portofolio teknis nyata di GitHub.

---

### 1. Situation (Konteks & Latar Belakang)
Di pasar rekrutmen perangkat lunak modern, para insinyur berbakat sering menghadapi dua hambatan besar:
1. **Penyaringan Mesin ATS yang Kaku:** Mesin ATS seperti Greenhouse dan Workday menolak format resume dengan layout multi-kolom, grafik skill bar, atau icon visual yang tidak ramah parser teks.
2. **Kebutuhan Bukti Konkret:** Rekruter dan Engineering Manager menuntut tautan langsung ke repositori nyata yang memiliki automated unit testing, dokumentasi arsitektur, dan kepatuhan kode produksi, bukan sekadar klaim keahlian di atas kertas.

---

### 2. Task (Tantangan Rekayasa)
Merancang aplikasi web performa tinggi menggunakan Next.js 16 App Router dan TypeScript yang menyajikan studi kasus STAR mendalam, dilengkapi mesin generator resume berbasis AI multimodal (Google Gemini) yang mampu memindai teks atau tangkapan layar lowongan pekerjaan, memetakan kualifikasi yang dibutuhkan secara deterministik ke repositori GitHub kandidat, dan mengekspor dokumen linear A4 berstandar ATS.

---

### 3. Action (Implementasi Arsitektur)
- **Ekstraksi Multimodal Vision:** Integrasi `@ai-sdk/google` untuk memproses tangkapan layar loker melalui Gemini Vision OCR tanpa memerlukan layanan OCR pihak ketiga yang berbayar.
- **Grounding Data Proyek Riil:** Mengunci basis pengetahuan AI ke data portofolio terverifikasi di GitHub guna mencegah halusinasi data profil, proyek palsu, atau riwayat fiktif.
- **Layout Cetak A4 Tanpa Dependensi:** Menyusun stylesheet `@media print` presisi tinggi yang mereplikasi format baku A4 sehingga proses konversi ke PDF dapat dilakukan langsung melalui browser engine tanpa library rasterisasi berat yang membebani memori.
- **Verifikasi Kualitas Berkelanjutan:** Menyertakan 123 automated test suites dengan Vitest dan strict type-checking TypeScript untuk menjamin stabilitas runtime.

---

### 4. Result (Dampak Terukur)
- Lolos 100% uji parsing ATS teks linear satu kolom.
- Waktu muat awal di bawah 1 detik dengan performa rendering 60 FPS.
- Zero-Hallucination: seluruh klaim CV berbasis langsung pada proyek nyata di GitHub.
