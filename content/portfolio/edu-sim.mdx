# Sensei Edu-Sim Suite: Mesin Simulasi Visual 60 FPS Mandiri Satu File HTML

Sensei Edu-Sim Suite adalah terobosan media peraga sains dan matematika interaktif yang memadukan rekayasa grafis kanvas 2D tingkat tinggi dengan prinsip pedagogi diagnostik sokratik dalam satu file HTML mandiri.

---

### 1. Situation (Konteks & Akar Masalah)
Laboratorium sekolah di berbagai daerah menghadapi keterbatasan infrastruktur teknologi:
- Komputer sekolah sering kali memiliki spesifikasi memori terbatas (RAM 4GB–8GB) dan koneksi internet yang lambat atau tidak stabil.
- Perangkat lunak simulasi komersial berukuran ratusan megabyte, memerlukan lisensi mahal, atau memuat lusinan script CDN pihak ketiga yang gagal dimuat saat offline.
- Pendekatan konvensional yang memakai fungsi `eval()` JavaScript untuk mem-parsing rumus matematika membuka celah keamanan injeksi skrip berbahaya (*Arbitrary Code Execution*).

---

### 2. Task (Tantangan & Batasan Arsitektur)
- **Single-File Architecture:** Seluruh kode (HTML semantic, styling CSS, JavaScript logic, ikon SVG inline) wajib berada dalam satu file `.html` tunggal berukuran < 40KB.
- **Zero External Dependencies:** Tidak boleh memuat CDN, React, Tailwind runtime, atau library grafik eksternal.
- **Zero-Eval Mathematical Safety:** Evaluasi formula aljabar dan trigonometri wajib diproses melalui custom parser berbasis grammar AST.
- **60 FPS Performance:** Siklus render visual kanvas wajib mempertahankan 60 frame per detik tanpa membebani GPU/CPU.

---

### 3. Action (Kontribusi Rekayasa Teknis Nyata)

#### A. Recursive Descent Math Parser (Zero-Eval)
Membangun tokenizer dan parser prediktif dari nol:
- Memproses ekspresi aritmatika: `+`, `-`, `*`, `/`, `^`, serta fungsi matematika `sin`, `cos`, `tan`, `sqrt`, `abs`, `log`, `exp`.
- Mencegah eksekusi script injeksi sepenuhnya karena parser hanya mengenali token angka dan operator yang terdaftar.

#### B. Kanvas 2D Dinamis & Adaptive Coordinate Grid
Mengembangkan sistem kanvas interaktif:
- Transformasi matriks koordinat dua arah: *World Coordinates (x, y)* ↔ *Screen Pixels (px, py)*.
- Infinite Pan & Zoom dengan penyesuaian interval garis kisi (sub-grid otomatis bertransisi antara 0.1, 0.5, 1, 5, 10, dst. tergantung skala zoom).
- Probe koordinat kursor interaktif yang menampilkan nilai titik f(x) secara real-time.

#### C. Modul Evaluasi Sokratik HOTS
Menyematkan kuis penalaran konsep:
- Pertanyaan berakar pada prinsip sebab-akibat (misal: "Apa yang terjadi pada puncak kurva jika koefisien 'a' diubah menjadi negatif?").
- Analisis distraktor instan: Jika siswa memilih opsi yang salah, sistem memaparkan kekeliruan nalar mereka dan mengarahkan kembali ke analogi fisik pertama.

---

### 4. Results & Metrics (Dampak Terukur)

- **Ukuran Berkas 38 KB:** Total ukuran file kurang dari satu gambar thumbnail standar, memungkinkan distribusi instan via WhatsApp atau flash disk.
- **60 FPS Flawless Rendering:** Berjalan stabil pada peramban Chrome, Edge, Safari, dan Firefox di laptop low-end.
- **0 Dependensi Eksternal:** Beroperasi 100% secara offline dalam lingkungan *air-gapped*.
- **12/12 Lulus QA Audit:** Terverifikasi bebas dari memory leak, requestAnimationFrame loop tak terkontrol, dan aman dari kerentanan keamanan konten.
